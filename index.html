    Introduction étape par étape au framework mobile [Ionic]

    créé par l’IA Claude d’Anthropic à la demande de Serge Tahé - octobre 2026

    |English version|

    Ce cours apprend à écrire, pas à pas, une application mobile avec le framework Ionic, associé à Angular et à Capacitor : une application Android, dont les écrans sont fabriqués sur le téléphone à partir des données JSON d'un serveur. C'est une application web (HTML, CSS, TypeScript) que Capacitor emballe dans une application Android : le même code tourne aussi dans un navigateur.

    Après la mise en place de l'environnement de travail, il s'appuie sur 25 petits exemples, chacun centré sur une seule notion : les composants d'Ionic, les signaux et les valeurs calculées, les gabarits, les événements, tous les types de champs, la validation et les formulaires réactifs ; les entrées et les sorties des composants, la projection de contenu, le cycle de vie, l'injection de dépendances, les directives, les fenêtres d'Ionic ; le routage avec ion-tabs et les gardes ; l'asynchrone et l'état partagé (Promise, Observable, resource, services et signaux, @capacitor/preferences) ; l'internationalisation ; enfin le dialogue avec le serveur (HttpClient, proxy de développement, requêtes natives sur Android, cookie du jeton).

    Le serveur est traité comme une boîte noire : c'est le serveur JSON de l'application RdvMedecins, écrit avec NestJS. On l'installe, on étudie son API et on l'interroge avec 48 exemples curl, sans avoir à lire son code.

    Vient ensuite une étude de cas complète : le client Ionic de RdvMedecins, une application de prise de rendez-vous pour un cabinet médical, dont tous les fichiers sont commentés, puis son déploiement, sur le web et sur Android.

    Prérequis : les bases d'Angular et de TypeScript, présentées dans les cours Introduction étape par étape au framework Angular et Introduction au langage TypeScript par l'exemple. Les 25 exemples portent les mêmes numéros, et montrent les mêmes écrans, que ceux des cours Flutter, React et Vue.js.
